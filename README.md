# Codveda Java Development Internship

This repository contains six Java projects completed as part of the **Codveda Technology Java Development Internship**.

The projects are organized into three levels, with two tasks completed in each level.

## 📁 Projects

### Level 1 – Beginner

**1. Basic Calculator**
- Performs basic arithmetic operations.
- Supports addition, subtraction, multiplication, and division.

**2. Number Guessing Game**
- Generates a random number.
- Allows the user to guess the number.
- Provides feedback to help the user find the correct answer.

### Level 2 – Intermediate

**3. Employee Management System**
- Add, view, update, and manage employee records.
- Uses Object-Oriented Programming (OOP).
- Stores employee data using an ArrayList.

**4. Simple Banking Application**
- Deposit money.
- Withdraw money.
- Check account balance.
- Uses methods and basic banking operations.

### Level 3 – Advanced

**5. Library Management System with JDBC**
- Connects a Java application to a MySQL database using JDBC.
- Add, view, update, and delete books and users.
- Borrow and return books.
- View borrowing transactions.

**6. Binary Search Tree**
- Insert nodes into a Binary Search Tree.
- Search for values.
- Delete nodes.
- Perform Inorder, Preorder, and Postorder traversals.

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Collections (ArrayList)
- JDBC
- MySQL
- Maven
- IntelliJ IDEA

## ▶️ How to Run

1. Clone or download this repository.
2. Open the required project in IntelliJ IDEA.
3. Make sure the JDK is installed.
4. Run the `Main.java` file.

**For the Library Management System:**
- Install and configure MySQL.
- Create the `java_library` database and required tables.
- Configure the database URL, username, and password in `DBConnection.java`.
- Reload Maven dependencies before running the application.
